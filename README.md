# Bilel AI Studio

Bilel AI Studio est une application web premium de création de vidéos marketing et de contenu social avec intelligence artificielle.

## Fonctionnalités

- Interface premium orientée marketing digital
- Création de contenus à partir d’une idée
- Script IA prêt à utiliser
- Storyboard intelligent
- Sélection de style visuel et plateforme de diffusion
- Prévisualisation de la vidéo
- Export de projet en file de rendu

## Stack technique

- React
- Vite
- JavaScript

## Démarrage rapide

1. Installe les dépendances :
   ```bash
   npm install
   ```
2. Lance le projet :
   ```bash
   npm run dev
   ```
3. Ouvre l’application dans le navigateur :
   ```bash
   http://localhost:3000
   ```

## Objectif

Cette première version est une base ultra-pro pour un studio de création de vidéos professionnelles pour les réseaux sociaux, les reels, les stories, les annonces et le marketing digital.

## Nom de marque

Bilel AI Studio

## Remarque

Cette version est une interface de démonstration professionnelle. Elle peut ensuite être étendue avec un vrai backend IA, génération de voix, génération de visuels, export vidéo avancé et intégration de modèles d’IA.
